# Tecnologías del proyecto — For Magos

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Crear la estructura y el diseño visual del sitio web. |
| Versionado | Git y GitHub | Guardar y controlar los cambios realizados en el proyecto. |
| Publicación | GitHub Pages | Publicar el prototipo web de For Magos. |
| Diseño | Whimsical | Crear wireframes y organizar la estructura del sitio. |
| Diseño | Google Stitch | Diseñar y generar el prototipo visual de la página. |
| IA | Gemini | Apoyar la creación y mejora de contenido y código. |
| Editor | Antigravity | Editar y organizar los archivos y código del proyecto. |

## Qué es funcional y qué es prototipo

| Funcionalidad | Estado en esta versión |
|---|---|
| Navegación entre páginas y categorías | Funcional |
| Visualización del catálogo | Funcional |
| Búsqueda de productos | Prototipo visual |
| Filtros de productos | Prototipo visual |
| Selección de talla | Prototipo visual |
| Carrito de compras | Prototipo visual |
| Proceso de pago | Prototipo visual |
| Formulario de contacto | Prototipo visual |

## Integraciones para una versión real

- Plataforma de pago como Mercado Pago.
- WhatsApp para atención al cliente.
- Instagram de For Magos.
- Sistema real de inventario y stock.
- Sistema de envíos y seguimiento de pedidos.

## Restricciones

- **Plazo:** Desarrollo dentro del periodo establecido para la evaluación.
- **Marca:** Mantener la identidad visual de For Magos, utilizando principalmente negro, blanco y dorado suave.
- **Dispositivos:** Diseño responsive para computador, tablet y celular.
